# Автоматизация тестирования функционала поиска билетов и отелей на агрегаторе Aviasales.

## Описание проекта:

Цель данного проекта — автоматизация тестирования функционала поиска билетов на платформе Aviasales. Тестирование включает как позитивные, так и негативные проверки, чтобы гарантировать корректную работу сайта. Для тестирования используются UI и API тесты и библиотеки pytest, requests, Selenium, Allure.

Основные тесты включают проверку корректности поиска билетов и отелей с различными параметрами, такими как пункт отправления и прибытия, название отеля или города, в котором мы его ищем, дата вылета/прибытия. Для всех тестов можно сформировать отчёт в Allure.

## Структура проекта:
Проект включает в себя следующие файлы:

test*.py — название тестов.
settings.py — содержит настройки окружения и тестовые данныес.
requirements.txt — файл с зависимостями проекта.
README.md — описание проекта и инструкция.
pytest.ini - файл конфигурации pytest для создания маркеров "ui" и "api".


### Для запуска тестов используйте pytest. Для выполнения всех тестов используйте следующую команду:

pytest --alluredir=allure-results

Для генерации отчетов в формате Allure выполните команду:

allure serve allure-results

### Всего в проекте 10 автоматизированных тестов с дополнительными проверками для увернности в результате.
В 5 из них производится тестирование API, в остальных 5 - тестирование интерфейса (UI).

Проект поддерживает три режима запуска через маркеры (pytest -m "ui", pytest -m "api", pytest).
